# Landing Page

The landing page is a static NextJS application used for our GitHub Pages webpage, which can be accessed
[here](https://gchq.github.io/Bailo/).

<!-- GETTING STARTED -->

## Local development

### Requirements

- Node v26

### Prerequisites

`npm run generate` copies files produced elsewhere in the repository. Generate them first:

- Python Sphinx documentation: follow [backend/docs/README.md](../../backend/docs/README.md).
- Backend config documentation and OpenAPI specs, from within the `backend` directory:

```bash
npm i
npm run generate-config-docs
npx tsx src/scripts/generateOpenApiSpecs.ts
```

### Development Build

In order to start the application locally for development/testing, you will need to run the following commands:

```bash
# Install dependencies
npm i
# This copies over some components/files from the frontend to be re-use, and also user and python documentation generated by Sphinx
npm run generate
# Start the dev server
npm run dev
```

You can then access the site by going to [localhost:3000](http://localhost:3000).
