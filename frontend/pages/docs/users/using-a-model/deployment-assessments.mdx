# Using Deployment Assessments

> **Common questions this page answers:**
>
> - What are Deployment Assessments?
> - How do I create a Deployment Assessment?
> - How do I publish a Deployment Assessment?

## What are Deployment Assessments?

Deployment assessments are used to document the use of one or more models. Unlike the previous access request process,
Deployment Assessments are not tied to individual models, and model owners or managers do not necessarily need to be
involved.

The author of a Deployment Assessment is responsible for its contents as the Deployment Risk Owner. There is no separate
review or approval step.

## Creating a Deployment Assessment

To create a Deployment Assessment:

1. Navigate to the **Deployment Assessments** page.
2. Select **Create Deployment Assessment**.
3. Choose the appropriate assessment schema.
4. Complete the assessment form, providing all required information. Required fields are clearly marked.
5. Select **Save draft** to keep working on the assessment later, or **Publish** to create and publish it immediately.

## Drafts and publishing

A draft Deployment Assessment can be edited as many times as needed. Required fields do not need to be completed while
the assessment is a draft.

When the assessment is complete, open it and select **Publish** in the draft banner. All required fields must be
completed before an assessment can be published. Publishing cannot be undone - a published assessment cannot be returned
to a draft.

Any additional Deployment Risk Owners and the owners of the included models are notified by email when an assessment is
published.

## Commenting on a Deployment Assessment

Comments can be added at the bottom of a Deployment Assessment page to discuss its contents.
