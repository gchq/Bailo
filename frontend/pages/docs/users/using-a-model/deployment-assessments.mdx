# Using Deployment Assessments

> **Common questions this page answers:**
>
> - What are deployment assessments?
> - How do I create a deployment assessment?
> - What happens after I submit a deployment assessment?

## What are deployment assessments?

Deployment assessments are used to document and approve the use of one or more models. Unlike the previous access
request process, deployment assessments are not tied to individual models, and model owners or managers do not
necessarily need to be involved in the review process.

The deployment assessment process is designed to reduce the administrative overhead associated with obtaining approval
to use models. Under the previous process, users were required to submit a separate access request for each model and
wait for approval from a model owner or manager. With deployment assessments, a single assessment can cover multiple
models, simplifying the approval process.

## Creating a deployment assessment

To create a deployment assessment:

1. Navigate to the **Deployment Assessments** page.
2. Select **Create deployment assessment**.
3. Choose the appropriate assessment schema.
4. Complete the assessment form, providing all required information. Required fields are clearly marked.
5. Select **Submit** to create and submit the assessment for review.

## Review process

Deployment assessments are reviewed by a single Deployment Risk Owner (DRO). The DRO is selected by the person creating
the assessment and is responsible for reviewing the information provided and determining whether the proposed use should
be approved.

The DRO does not need to be involved in the ownership or management of any models included in the assessment.
