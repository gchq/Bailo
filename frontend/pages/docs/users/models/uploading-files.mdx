# Uploading Files

Files represent any artefacts related to a model, such as binaries, configuration files, or supporting documentation.
These files allow others to build, evaluate, and use your model.

> **Common questions this page answers:**
>
> - How do I upload files to a model in Bailo?
> - How do I attach files to a release?
> - How do I upload files programmatically?

## Adding files to a model

Upload files from the **File Management** tab on your model page:

1. Click **Add new files**
2. Select files or folders to upload
3. Optionally assign tags to each file

## Adding files to a release

When creating or editing a release, you can attach files in two ways:

- **Select existing files** — choose from files already uploaded to the model
- **Upload new files** — opens the upload dialog to upload files directly, which are then automatically added to the
  release

Files on a release are displayed in a folder-navigable browser. You can remove a file from a release using the context
menu (⋮) on each file or folder row — this detaches the file from the release without deleting it from the model.
