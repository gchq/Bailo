# Viewing and Comparing Model Cards

> **Common questions this page answers:**
>
> - How do I view an earlier version of a model card?
> - How do I compare two versions of a model card?
> - Can I compare model cards from different models?
> - How do I read the highlighted changes on the comparison page?

Each edit to a model card creates a new version. Bailo keeps every version, so you can view the model card exactly as it
was at an earlier point, or compare two versions to see what changed between them. You can compare versions from the
same model or select model cards from different models.

This is useful when checking what a model card said at a particular time, reviewing changes to model documentation,
checking how models differ, or verifying that updates have been recorded correctly.

## Viewing model card history

If you want to see every version of a model card, open its history:

1. Open the model and go to the **Overview** tab
2. Open the model card actions menu
3. Select **View History**

The history dialog lists each version, newest first, along with who created it and when.

## Viewing a specific version

You can open any single version of a model card in read-only form. To do this, select its row in the history dialog. The
page shows the model card exactly as it was when that version was created.

An information banner at the top of the page confirms that a single card is being shown. To see how this version differs
from another, select a version on the **To** side to switch to a comparison.

Each version you view has its own unique URL. You can copy the URL from your browser and share it so that others open
the same version of the model card.

## Selecting model cards to compare

If you want to see what changed between two versions, select them for comparison:

1. Open the model card history dialog, or go directly to the model card comparison page
2. Tick the **Compare** checkbox for the two versions you wish to compare
3. Select **Compare revisions**

The older version is always used as the **From** card and the newer version as the **To** card.

Each comparison also has its own unique URL, which records the selected models and versions. You can share this URL so
that others see the same comparison.

## Comparing model cards

After selecting two model cards, the comparison page displays a single copy of the model card with the differences
between the selected cards highlighted inline. Each answer shows what changed from the **From** card to the **To** card.

## Reading the differences

The comparison page marks changes in each answer:

- **+ with a green highlight** - content that appears in the **To** card but not the **From** card
- **- with a red highlight** - content that appears in the **From** card but not the **To** card
- **No highlight** - content that is the same in both cards
- **_Unanswered_ inside a change** - the question had no answer in that card
- **_Unanswered_ without a highlight** - the question has no answer in either card

How a change is shown depends on the type of answer:

- **Text answers** - only the words that changed are highlighted, so you can see small edits within a longer answer
- **Rich text answers** - formatting such as headings, lists, tables and links is kept, and the changed parts are
  highlighted within it
- **Images** - a changed item is shown in full, with the old version marked **-** and the new version marked **+**, each
  inside a coloured frame
- **Performance metrics** - changes to metric names and values are highlighted row by row, and metrics that were removed
  are still listed so that you can see what was taken out
- **Other answers** - dates, selections, tags and users are compared as text

## Comparing versions of the same model

When comparing versions of the same model, you can review how the model card has changed over time.

For example, you might compare:

- The current version with an earlier version
- A version before and after a model lifecycle status update
- Two versions created during a review
- A released model card with its latest draft

Comparing versions helps you understand what information was added, updated, or removed between those versions.

## Comparing cards from different models

Model card comparison also allows you to select cards from different models. This can help you review the documentation
for related or alternative models.

When comparing different models, consider whether:

- The models use the same model card schema
- The fields contain equivalent information
- The models have different intended uses or limitations
- Differences are caused by the models themselves or by the information recorded in their cards

The comparison shows the information recorded in each selected model card. It does not indicate that one model is better
or more suitable than the other.

## Mirrored models

Mirrored model cards can also be included in model card comparisons. A mirrored model is a copy of a model from another
Bailo instance, with a read-only source card and an editable local card.

When comparing a mirrored model with a non-mirrored model, Bailo compares:

- The read-only source card from the mirrored model
- The editable local card from the non-mirrored model

Locally added information on the mirrored model is not used as the primary card in this comparison. The revision
selector therefore shows source-card revisions for the mirrored model and local-card revisions for the non-mirrored
model.

This behaviour is based on the model type rather than its position in the comparison. Swapping the **From** and **To**
models does not change which card is used. The mirrored source content remains read-only and is not overwritten or
changed by the comparison.
