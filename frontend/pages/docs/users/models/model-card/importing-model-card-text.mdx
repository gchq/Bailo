# Importing a Model Card from Text

<FeatureAvailability feature='llmImport' />

> **Common questions this page answers:**
>
> - How do I populate a model card from existing documentation?
> - What text formats does the import feature support?
> - What happens when I run the import?

If your model already has written documentation, you can use the text import feature to extract relevant information
into your model card form automatically, instead of filling in each field by hand.

## Supported formats

The import works with any plain text that describes a model, structured or unstructured, including:

- HuggingFace model card README files
- AI system cards (for example Claude or GPT model cards)
- Internal model documentation

## How to use

1. **Create your model** following the normal workflow - provide a name, description, and select a schema
2. Navigate to your model's **Overview** tab and click **Edit Model Card**
3. Click the **Import from Text** button in the toolbar
4. In the dialog that appears, paste the full text of your existing model card or documentation
5. Click **Extract** - Bailo sends the text to an LLM, which extracts information into the schema fields
6. Review the extracted data. Fields that could not be populated from the source text remain blank
7. Make any corrections or additions, then click **Save**

## What to expect

- The extraction only uses information that is **explicitly present** in your source text. It will not guess or infer
  values
- Extracted values are checked against the schema. Values that do not fit the schema, or that look like placeholders,
  are discarded and listed as validation warnings in the notification shown after the import
- Some fields (such as internal references to data cards or user entities) cannot be populated from text and always
  remain blank
- Each import replaces all current form data, so run the import before making manual edits. You can run it as many times
  as you need
- Nothing is saved automatically. AI-extracted data may be incomplete or inaccurate, so always review it before saving
